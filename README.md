# Hospital-Management-Database

A relational database system developed using Oracle Database to manage core hospital operations, including patients, doctors, departments, appointments, medications, and prescriptions.

## Features
- Designed relational database tables with primary and foreign key constraints
- Implemented SQL DDL and DML statements
- Created user roles and privileges for access control
- Developed stored procedures and functions
- Implemented triggers to enforce business rules
- Created indexes for query optimization
- Used JOIN queries to improve data retrieval

## Database Entities
- Patient
- Doctor
- Department
- Appointment
- Medication
- Prescription

## Technologies
- Oracle Database
- SQL
- PL/SQL
